## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Profile Editor** | Design trigger resistance and haptic feedback patterns visually |
| **Game Library** | Link saved profiles to specific games for auto-apply on launch |
| **Preset Templates** | Start from built-in templates for FPS, racing and action games |
| **Quick Apply** | Switch any saved profile without reopening the full DSX app |
